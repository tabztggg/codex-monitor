提供带运行环境的安装包：Windows EXE、macOS Intel / Apple Silicon PKG、Linux x64 / ARM64 DEB 和便携包。

- 安装后直接打开浏览器使用，不再要求使用者安装 Node、Git 或 npm。
- 补齐快捷方式、登录自启动和卸载；配置、用量缓存与程序分开保存。
- 网页更新改用稳定 Release，下载校验后切换，启动失败回退；原有源码安装方式继续保留。
- 修复隐藏目录下子页面打不开的问题，退出时关闭私有 Codex 查询进程。

安装包未签名、未做 Apple 公证。请按系统和架构选择文件，可用 SHA256SUMS.txt 核对下载。[安装与迁移说明](https://github.com/tabztggg/codex-monitor/blob/main/docs/installation-packages.md)

Bundled-runtime installers for Windows, macOS and Linux. Adds desktop/menu entries, login startup, persistent user data and stable-release updates with startup rollback. Existing source installs remain supported. Packages are unsigned and not notarized.
