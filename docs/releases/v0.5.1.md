# v0.5.1 — 2026-09-28

提供 Windows x64 EXE、macOS Intel／Apple Silicon PKG、Linux x64／ARM64 DEB 与便携包，内置 Node.js 和 Codex CLI。支持快捷启动、登录自启动、独立数据目录及稳定 Release 更新，启动失败回退；源码安装继续保留，账号需自行登录。

新增 5 项分析功能：

- **模型对比：** 按所选时间范围比较跨账号 Token、缓存命中率、任务数和 API 等价费用，可排序。
- **日趋势与任务下钻：** 柱形按模型堆叠，点击日期查看当天模型和任务，任务链接保留日期。
- **历史缓存效率：** 总缓存输入 ÷ 总输入，支持每日查看，缓存不重复计入总 Token。
- **价格依据：** 显示单价、来源、逐模型核对日期、定价覆盖率、未定价模型及计价假设。
- **报告导出：** 按需下载离线 HTML／CSV／JSON，覆盖所选日期和归档范围；默认使用别名，可选显示名称，不导出账号身份、路径、会话 ID 或聊天原文。

**实时 Token“1 秒”**为最近 1 分钟输入／输出除以 60 的均值；命中率和任务数仍按该分钟统计，不增加采集频率。实时记录仅在内存保留最多 1 小时，重启重新累计。

费用是 **API 等价估算，不是订阅账单或官方额度扣减**。未知模型和缺失数据明确标记；官方任务累计用量仍独立显示。

**安装包未签名、未做 Apple 公证。** 请按系统和架构下载，用 `SHA256SUMS.txt` 核对文件。[安装、迁移与卸载说明](https://github.com/tabztggg/codex-monitor/blob/main/docs/installation-packages.md)

修复原生安装包验证中的启动／重启时序校验，等待服务和管理状态均就绪。已有本地测试记录：682 项通过，2 项跳过。

## English

Bundled-runtime installers for Windows, macOS and Linux add shortcuts, login startup, separate user data and stable-release updates with rollback. Source installs remain supported. Packages are unsigned and not notarized; verify downloads with `SHA256SUMS.txt`.

Adds model comparison, daily model stacks with task drilldown, weighted cache efficiency, pricing coverage and default-anonymized HTML/CSV/JSON exports. The 1-second view is the last minute's input/output divided by 60, with no extra polling. Costs are estimates, not subscription charges. Package smoke checks now wait for both service and manager readiness during startup/restart. Recorded local tests: 682 passed, 2 skipped.
