# v0.5.2 — 2026-10-02

- **账号额度对账：** 所选账号的任务用量按本周期记录到的额度增量分配；纳入任务、范围外任务和未归属额度合计对应账号已用额度。
- **校准隔离：** 避免其他账号或过期手动基准影响当前任务；记录覆盖不足时保留历史跨账号基准，查看历史账号不会重新训练基准。
- **统计修复：** 支持读取超大的旧工具完成记录，保留日志校验和读取上限；补充 GPT-6.1 Sol 定价，并从缓存重算历史费用。
- **界面：** 新增中英文对账说明和网页标签图标，更新三个页面的深浅色演示截图。

任务归属仍是本地记录估算，不能恢复其他设备或缺失日志的消耗；未归属部分单独显示。费用是 API 等价估算，不是订阅账单。

验证：本地 697 项测试通过、2 项跳过；类型检查和构建通过。五个平台的构建、启动和安装验证全部通过后才发布安装包。

Windows、macOS、Linux 安装包与便携包包含 Node.js 和 Codex CLI。安装包未签名、未做 Apple 公证；下载后用 `SHA256SUMS.txt` 核对。[安装说明](https://github.com/tabztggg/codex-monitor/blob/v0.5.2/docs/installation-packages.md)
