# v0.5.3 — 2026-10-07

- Fix task statistics and live tokens failing on oversized compaction records, without recounting copied historical usage.
- Allocate observed quota for unpriced models using token weights. Unknown USD prices and unattributed quota remain explicit.
- Use quota allocations within the selected range for cross-account totals, daily trends and rankings; estimate only uncovered priced records. Fix duplicate, zero-usage and reset-boundary cases.
- Clarify account-period versus date-range totals, display the statistics time zone and update bilingual light/dark screenshots.

Task attribution remains an estimate from local records. Missing logs and other-device usage cannot be reconstructed; API-equivalent costs are not subscription charges. “Today” uses midnight on the Monitor computer, not the start of the account quota period.

Local verification: 749 tests passed, 2 skipped; type checking and production build passed. All five package targets must pass build, startup and installation checks before publication.

Windows x64, macOS Intel/Apple Silicon and Linux x64/ARM64 installers and portable archives include Node.js and Codex CLI. Packages are unsigned and not notarized; verify `SHA256SUMS.txt`. [Installation guide](https://github.com/tabztggg/codex-monitor/blob/v0.5.3/docs/installation-packages.md)

## 简体中文

- 修复超大压缩上下文导致任务统计和实时 Token 读取失败，不重复计算其中的历史用量。
- 未定价模型按 Token 权重参与已观测额度的任务分配，未知费用和未归属额度单独保留。
- 跨账号汇总、每日趋势与排行按所选范围内的额度归属计算，仅对未覆盖的有价格记录补估；修复重复、零用量和周期边界。
- 明确账号本周期与所选日期范围的区别，显示统计时区，更新中英文深浅色截图。

任务归属仍是本地记录估算，不能补回缺失日志或其他设备的消耗；费用不是订阅账单。“今天”按 Monitor 电脑的当地零点开始，账号额度则按重置周期累计。

五个平台安装包与便携包包含 Node.js 和 Codex CLI，发布前须通过各平台构建、启动和安装验证。安装包未签名、未做 Apple 公证，请核对 `SHA256SUMS.txt`。
