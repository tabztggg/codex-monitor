# Codex Monitor v0.5.4

- Add GPT-6.1 Terra API-equivalent cost estimates using OpenAI's standard token rates.
- Recalculate cached history with the new pricing without reopening archived transcripts.

Estimates use standard-speed rates and 30-minute cache writes. They are not subscription charges; missing records and other speed or retention settings can affect the estimate. [Pricing source](https://developers.openai.com/api/docs/models/gpt-6.1-terra)

Windows x64, macOS Intel/Apple Silicon and Linux x64/ARM64 packages include Node.js and Codex CLI. Packages are unsigned and not notarized; verify `SHA256SUMS.txt`. [Installation guide](https://github.com/tabztggg/codex-monitor/blob/v0.5.4/docs/installation-packages.md)

## 简体中文

- 按 OpenAI 官方标准 Token 价格，增加 GPT-6.1 Terra 的 API 等价费用估算。
- 自动从缓存重新计算历史用量，无需重新读取已归档的原始对话。

估算使用标准速度和 30 分钟缓存写入价格，并非订阅账单；缺失记录、其他速度或缓存期限会影响估算。

提供 Windows x64、macOS Intel／Apple Silicon 和 Linux x64／ARM64 安装包及便携包，内含 Node.js 和 Codex CLI。安装包未签名、未做 Apple 公证，请核对 `SHA256SUMS.txt`。
