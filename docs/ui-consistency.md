# UI 统一口径

六张生成图仅供布局参考，以下规则优先于图片文字与示例数值。

- 全页共享深蓝背景、蓝色选中态、同一顶栏和按钮样式。总览、任务、趋势为独立页面，导航共享状态。
- 总览只显示当前登录账号的额度；任务明细保留历史账号选择，两者互不替换。历史账号按最近快照统计，不宣称实时刷新。
- 官方账号额度显示已用/剩余百分比和重置时间，不虚构 Token 配额、月费或 Pro 档位。
- 任务额度列统一为“额度消耗（所选套餐等效）”，左侧所选账号本周期、右侧跨账号任务累计，各自排序。允许超过 100%。
- 汇总时间选择仅影响明确标注的范围汇总、费用、Token 和趋势；不能偷偷改变任务额度两侧的时间口径。
- 费用是 API 等效估算美元，非订阅账单。总 Token 是计数；未知显示 --，部分数据加 +，真实零保留。
- 归档默认只读取最近 30 个；统计全部与隐藏归档是不同操作。项目分组默认关闭，聚合沿用当前表格指标口径。
- 刷新保留旧值及原范围，成功后替换。保留 30 秒、1/2/5/10 分钟和立即刷新、重建统计。
- 视图选项保持完整/精简、密度、列显示和排序；不复制生成图中重复的统计卡。
- 服务按钮位于语言左侧。重启/停止均需确认，停止后用桌面快捷方式启动。服务停止不同于 Windows 自动关机。
- 自动关机只展示实际已有的状态和操作；不添加图片虚构的时长编辑器。演练模式明确不会关机，开关文字与真实状态一致。
- 中英文使用同一布局。首次默认英语，记住上次选择。示例任务不作为新增功能要求。

生成图中不一致的标志、按钮、日期、金额公式、Token 分母及开关标注均作废；最终以真实网页截图验收。

- 趋势页固定跨账号，不显示账号筛选；日趋势指标只控制日图，排行固定为所选范围内的套餐等效额度。横条统一比例，可超过一份额度，数字不归一化。
- 三页都显示归档覆盖范围。今日活动按服务端时区；无日期记录在趋势上标示部分数据。
- 总览账号卡常显完整额度周期和快照时间，来源继续折叠。范围任务数只计有记录消耗的任务，纳入统计总数在数据覆盖中显示；无记录不当作零消耗。
- 总览 Token 拆分为输入、输出，缓存标为输入的子集。消耗 TOP 3 跟随统计时间范围，当前活动明确独立于日期筛选；数据覆盖与校准说明默认折叠。
